# Бенчмарк поиска

Бенчмарк измеряет полный вызов `Game::getAiMove()` на трёх фиксированных позициях:
дебют после `e2-e4`, позиция после восьми ходов итальянской партии и эндшпиль
с ферзём против ладьи и пешки. Подготовка позиции не входит в измерение.
По умолчанию проверяются глубины 1 и 2, по пять замеров после одного прогрева.
Результат — CSV с медианой, минимумом и максимумом времени в миллисекундах.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target chess_engine_search_benchmark -j2
./build/chess-engine/chess_engine_search_benchmark --iterations 7 --warmup 2 > before.csv
```

После изменения алгоритма соберите бенчмарк с теми же настройками и сохраните
результат в `after.csv`:

```sh
./build/chess-engine/chess_engine_search_benchmark --iterations 7 --warmup 2 > after.csv
python3 chess-engine/benchmarks/compare.py before.csv after.csv
```

Движок, сервер и benchmark собираются с `-O2` (или `/O2` в MSVC). Для честного
сравнения сначала сохраните CSV текущей версии, затем пересоберите изменённую
версию и повторите замер на той же машине с теми же параметрами.

`speedup` больше `1x` означает ускорение. `move_changed` показывает, изменился
ли выбранный ход; это полезно учитывать при сравнении двух версий поиска.
Для отдельной глубины используйте `--depth 2`; параметр можно повторять.
Замеры следует проводить на одной машине с одинаковой конфигурацией сборки.
